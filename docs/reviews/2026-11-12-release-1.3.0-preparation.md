## Merge and integration

The XML merge required reconciling ten files: acceptance plan, metadata tests, installed UI JavaScript tests, documentation index/editor guide, columns/home/troubleshooting/quick-start guides, and translations. Both sets of features and assertions were retained. The merged existing suites passed before adding combined-feature coverage.

Three new regression tests reproduced integration failures: Escape HTML rejected inactive XML delimiters; final modifier processing used a saved non-UTF-8 encoding and normalized XML text using a delimiter; modifiers flattened typed image/shipping values. XML now ignores delimited settings and uses UTF-8 throughout modifier processing. Typed values are transformed without mutating cached sources, and both structured output and scalar preview/validation representations reflect the change. Tests parse real Generic/RSS XML and verify comma-containing image URLs and punctuation in shipping services.

Documentation consolidates the feature guides under a 1.3.0 candidate baseline, adds release/upgrade/rollback notes and a wiki release page, and distinguishes candidate, tag, Composer indexing and wiki publication. No `composer.json` version literal was introduced: Composer resolves the release tag. Magento's historical schema `setup_version` is unchanged because this release adds no schema/data patch.
